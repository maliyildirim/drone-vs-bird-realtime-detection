## Rules

- Use only public-safe multirotor drone/bird material.
- Do not include fixed-wing UAV images, videos, screenshots, or metrics.
- Do not include personal file paths, student number, signatures, report scans, or private labels.
- Prefer 16:9 screenshots for GUI and sample outputs.
- Keep each image under 1-2 MB when possible.
- Use the exact filenames referenced in README.md.
